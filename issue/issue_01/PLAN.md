# issue/01 다음 렁 실행 계획 — exit-응집 항 v2 (계획만, 구현 없음)

작성 2026-07-17. 선행 렁(형성기-게이트 ΔF, κ3 배선)의 승격으로 공간 축은 열렸고, 27은
ΔF-적대로 판명 → 남은 최대 상방 = **시간 축**. 이 문서는 그 단일 계획이다(메뉴 아님).

## 1. 근거 사슬 (전부 실측 — deep_anatomy 2026-07-17 + 과거 원장)

1. **크기**: 잔여 ask = 38 −28~32M · 27 −18~20M(새 은행 vs 인증서 cap0.7 타깃). 막힘 순간의
   tardiness 가중 66~76%가 파편화.
2. **시간 축의 실측 크기** (reports/deep_anatomy/exit_prob_{38,27}.json):
   - 대형 queue 막힘 순간 중 **"직전 3일 exit이 응집됐다면 면적상 들어감" = 27 23.1% · 38 11.8%**
     — 27이 2배 비옥 = ΔF가 못 연 27의 직격 레버.
   - 3일-창에서 열린 면적-일의 **51%가 scatter**(응집 반사실), 이웃 exit 응집(≤3일) 현재값은
     19~20%뿐 = 항이 올릴 여지 실재.
   - 구멍 재충전 lag p50 1~2일·**소비자의 70~72%가 대형 block** → 구멍은 크게만 열리면 대형이
     즉시 먹는다 = **예약(보호)이 아니라 응집(크게 열기)**이 맞는 방향.
3. **과거 실측 전력**: 같은 형태의 항이 구(고정-bay) 기준선에서 ALNS 생존 승리(31 −5.5% 전
   seed·39 −1.8%)·풀 in-sample 혼잡8 −2.09%(38 −3.4% 포함)·LOO −1.00%. 제거 사유 = 기반 교체
   (측정 사망 아님).
4. **정직한 상한**: 막힘의 지배 성분은 '면적 조각은 있는데 모양이 안 받는' 층(66~80%) — e5는
   면적 프록시라 과대평가 가능. 현실 기대는 과거 실측 스케일: **27 −3~8% · 38 −1~4% +
   부수(39·31·26·30) 가능**.

## 2. 설계 (현 코드에 정확히 앉힘)

**메커니즘**: 배치 위치 점수에 "이웃 상주의 exit이 내 exit과 가까울수록" 가산 → 동시-퇴장
block이 공간적으로 뭉침 → 반출 때 구멍이 연속으로 열림.

- **config** ([Phase2/config.py](../../Phase2/config.py)): `dispatch_exit_cohort: float = 0.0`
  (0 = off = byte 동일) + `exit_cohort_scale: float = 1.0`(근접 커널 스케일 × pbar).
- **raster** ([Phase2/raster.py](../../Phase2/raster.py)):
  - `Raster.__init__(..., track_exit=False, exit_scale=1.0)` — off면 신규 코드 전부 미진입.
    exit_scale = cfg.exit_cohort_scale × pbar를 dispatch가 주입(검토 수정: pbar는 dispatch
    소유라 order_cells 인자가 아니라 생성자 배관 — dispatch의 pbar 계산을 Raster 생성 앞으로
    이동, 순수 계산 재배열이라 무영향).
  - 셀별 exit 그리드 `_exitg[j]`(int32, 0=빈칸): `add(j,i,o,pos, xt=None)`가 layer-0 마스크
    셀에 xt를 기록, `remove`는 감소 후 occ layer-0가 0이 된 셀만 0으로 클리어. ⚠️nestle 회수가
    hull 마스크 겹침을 허용하므로 셀 소유가 유일하지 않음 — "마지막 기록자 승리 + remove 시
    occ==0 셀만 클리어"로 근사: 겹침 셀에는 떠난 block의 exit이 잔류할 수 있음(결정적·휴리스틱
    필드라 정합성 불요 — ΔF pre-pass의 낡은 SAT 허용과 동일 원칙, 검토에서 명시화).
  - `order_cells(..., xt=None, cohort_w=0.0)`: 후보별 근접 필드 1회 구축 —
    `K = clip(1 − |_exitg − xt| / (scale·pbar), 0, 1)`(점유 셀만) → 기존 halo einsum과 동형의
    einsum 1회 추가 → `score += cohort_w · K-접촉`. 기존 contact·ΔF 항과 합산 구조 동일,
    tie-break(lexsort) 불변. 신규 스캔 0(FLOP 캡 불요), order_cells당 einsum 1회 추가가 비용의
    전부.
- **dispatch** ([Phase2/dispatch.py](../../Phase2/dispatch.py)): `_try_admit`·`_try_nestle`의
  커밋 경로 `raster.add(...)`에 xt 전달(**nestle 경로 포함 필수** — 안 하면 필드가 구멍남),
  `order_cells` 호출에 xt·cohort_w 전달. exit 제거 루프의 `raster.remove`는 시그니처 불변.
- **2차 변형(사전등록, 1차 실패 시만)**: ①형성기 게이트 재사용(`fragdelta_dens_hi`와 동형의
  δ0.55 — ΔF에서 "절정 활성 = 해"가 실측된 교훈의 이식) ②임계-스위치(체류 클래스
  c=⌈log₂P⌉별 부하 λ ≥ τ/√c일 때만 — τ는 reports/deep_anatomy의 e6 classload에서 도출).
  1차는 **plain(상시-켬)** — 과거 실측 승자가 plain이었으므로 검증된 형태부터.
